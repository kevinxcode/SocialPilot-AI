# Known limitations

- **Chrome must be open, online and logged in.** There is no server. If the laptop sleeps or Chrome is closed, posts miss their time. A post more than 2 hours late is skipped. When several slots are missed, only the latest one per platform is posted, so nothing goes out in a burst.
- **Meta UI changes break RPA** until the selector files are updated (see SETUP-RPA.md). The fixtures used in the tests are simplified copies of the page structure, not captures of the real Meta pages.
- **Terms of service.** Automated posting may break Meta's terms. Accounts can be rate-limited or restricted. Use it at your own risk.
- **An automation window appears** while posting. It is a normal window that doesn't take focus, because background tabs slow down rendering. Don't close it while a post is in progress.
- **One account per platform.** Multi-account and Business Suite aren't supported.
- **Video** can be attached manually; autopilot uses images only. Video upload through RPA hasn't been tested.
- **Engagement metrics** (likes, replies, reach) show as N/A. They are not collected or estimated.
- **Research** is generated by AI from general knowledge and your knowledge base. It is not real-time trend data. Competitor analysis uses only text or URLs you provide.
- **API keys** are stored unencrypted in `chrome.storage.local`, so anyone with access to this Chrome profile can read them.
- **Local folders** can only be read through a folder you pick in the directory picker or drag and drop. Imported files are copied into IndexedDB.
- **The Ollama origin rule** removes the `Origin` header on this extension's own requests to the configured Ollama host, so you don't need to set `OLLAMA_ORIGINS`.
- **Cost estimates** for OpenRouter use the published per-token prices. NVIDIA credit usage isn't priced, so it shows as "unpriced". Rupiah figures use a fixed rate of 16,000 IDR/USD.
